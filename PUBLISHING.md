# Publish on GitHub

1. Create a repository named `gopi-chandran-portfolio` (or use `YOURUSERNAME.github.io` for a user site).
2. Upload the contents of this folder to the repository root. Keep the `assets/` folder and its image path intact.
3. Open **Settings → Pages** and deploy from the `main` branch, `/ (root)`.
4. Update the GitHub and LinkedIn links in `index.html` after you know your profile URLs.
5. Test the Python examples locally using Python 3.10+ and `python -m pip install -r requirements.txt`.
6. Do not upload proprietary data, unpublished collaborators' data, or restricted research materials.

The portfolio is a starter. Verify every claim and replace any details that are outdated before publishing.
