Open any one of them.

Each project below opens as a short slide deck you can click through, and most carry a demo you can actually run in the browser - a control chart, a culture planning calculator, a database query console, a microsatellite finder. Every page with a demo has a button at the top that jumps straight to it. The code behind several of them sits in workflows/ in this repository.

How to read these: the science, methods, tools and reasoning are from my own project work. Where a demo needs data, it runs on clearly labelled example or synthetic input rather than raw lab or employer data, and each page says so. Published figures from the literature are cited to their source.
